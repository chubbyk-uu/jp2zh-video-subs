jp2zh-video-subs Windows CUDA Portable Setup
================================================

The application archive contains no model weights, user videos, or sample subtitles. It needs no
system Python, FFmpeg, or CUDA Toolkit, but Windows must have a working NVIDIA driver.

1. Extract the application

- Download jp2zh-video-subs-windows-x64-cuda-program.7z.001 and every following volume with the same base name.
- Place .001, .002, and all other volumes in the same directory.
- With 7-Zip or NanaZip, extract only .7z.001. Do not extract .002 separately.

For example, after extracting to D:\Tools, the application root is:

D:\Tools\jp2zh-video-subs\

2. Download the default models

In newer builds, first double-click jp2zh-subtitle-tool.exe and then click **Manage models...**
beside the model-status message:

- Click **Select current configuration**, confirm the download source, and click
  **Start download**.
- Checked models download sequentially in display order. Cancelling keeps partial files so the
  next attempt can resume.
- Installed models can be selected for re-download. Deleting a model always requires a second
  confirmation.
- **HF-Mirror (third-party)** is intended for public models. The application does not send a
  cached private Hugging Face token to that mirror.
- **Prefer Hugging Face/Xet (recommended)** is enabled by default and automatically falls back
  to compatibility HTTP. Turn it off to force resumable compatibility HTTP from the start.
- If either source is slow, enable **Use proxy (no authentication)** and enter a Windows
  HTTP/HTTPS proxy address without a username or password, for example
  http://127.0.0.1:7890. The proxy applies to both download modes; authenticated proxies
  are not currently supported.
- **Open Xet cache** and **Clear Xet cache** manage only the shared download cache. Clearing
  it keeps installed models, but future downloads may need to retrieve the same chunks again.
- Speed is the session average from the start of the current transfer. **Show download details**
  displays the source, proxy, current model, and errors.

If you prefer manual setup, open PowerShell or Command Prompt in the application root and run
each command below. Do not mix
the proxy syntax of the two shells. PowerShell does not search the current directory by default,
so the commands consistently use .\hf.cmd; that form also works in Command Prompt.

Important: **Prefer Hugging Face/Xet** and compatibility HTTP are GUI/project-downloader
options. `hf.cmd` wraps the official Hugging Face CLI and does not accept
`--download-backend`; do not append that option to the `hf.cmd download` commands below.
The manual commands pin the same upstream revisions as the current model catalog so later
default-branch changes cannot silently alter the downloaded files.

If Hugging Face is slow or blocked, set your Windows proxy in the same terminal first
(replace the example port with the one used by your proxy application).

PowerShell:

$env:HTTPS_PROXY = "http://127.0.0.1:7890"
$env:HTTP_PROXY = "http://127.0.0.1:7890"

Command Prompt (CMD):

set HTTPS_PROXY=http://127.0.0.1:7890
set HTTP_PROXY=http://127.0.0.1:7890

.\hf.cmd download litagin/anime-whisper --revision 22e2008a8182b357da3922a6308d095008f72973 --local-dir models\anime-whisper

.\hf.cmd download TransWithAI/Whisper-Vad-EncDec-ASMR-onnx model.onnx --revision 6ac29e2cbf2f4f8e9b639861766a8639dd666e9c --local-dir models\whisperseg

.\hf.cmd download Qwen/Qwen3-ForcedAligner-0.6B --revision c7cbfc2048c462b0d63a45797104fc9db3ad62b7 --local-dir models\Qwen3-ForcedAligner-0.6B

.\hf.cmd download SakuraLLM/Sakura-GalTransl-7B-v3.7 Sakura-Galtransl-7B-v3.7.gguf --revision 759d76b1745f4428308de6564c5ab710d4358b2e --local-dir models\Sakura-GalTransl-7B-v3.7-GGUF

The default Anime + GalTransl Simplified/Traditional Chinese workflow requires all four models above.

3. Optional models

Qwen ASR:
.\hf.cmd download Qwen/Qwen3-ASR-1.7B --revision 7278e1e70fe206f11671096ffdd38061171dd6e5 --local-dir models\Qwen3-ASR-1.7B

Sakura 14B Chinese translation:
.\hf.cmd download SakuraLLM/Sakura-14B-Qwen2.5-v1.0-GGUF sakura-14b-qwen2.5-v1.0-iq4xs.gguf --revision f370f85114971e556ba9ab7cdfd00fe9fe88dd53 --local-dir models\Sakura-14B-Qwen2.5-v1.0-GGUF

Sugoi 14B experimental English translation (manual review recommended):
.\hf.cmd download sugoitoolkit/Sugoi-14B-Ultra-GGUF Sugoi-14B-Ultra-Q4_K_M.gguf --revision d8dd836bf519a604530779cbf5ce13ffb35c3eeb --local-dir models\Sugoi-14B-Ultra-GGUF

Speaker-gender colouring:
.\hf.cmd download JaesungHuh/voice-gender-classifier --revision db1222153bd60337e900be22add7af180452adc0 --local-dir models\voice-gender-classifier

4. Start the application

Double-click jp2zh-subtitle-tool.exe.

The interface supports Simplified Chinese, Traditional Chinese, and English. Subtitle targets are
Simplified Chinese, Traditional Chinese, and experimental English. English uses Sugoi and should be
reviewed manually.

5. Verify downloads

- SHA256SUMS verifies the original .7z application archive after its volumes are reassembled in order.
- SHA256SUMS.parts verifies the downloaded split volumes directly.
