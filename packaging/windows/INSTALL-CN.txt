jp2zh-video-subs Windows CUDA 绿色版安装说明
================================================

程序包不包含模型权重、用户视频或示例字幕。解压后无需另装 Python、FFmpeg 或 CUDA Toolkit，
但 Windows 必须已安装可用的 NVIDIA 驱动。

1. 解压程序包

- 下载 jp2zh-video-subs-windows-x64-cuda-program.7z.001 及所有同名后续分卷。
- 将 .001、.002 等全部分卷放在同一目录。
- 使用 7-Zip 或 NanaZip，只解压 .7z.001；不要单独解压 .002。

例如解压到 D:\Tools 后，程序根目录为：

D:\Tools\jp2zh-video-subs\

2. 下载默认模型

新版本推荐先双击 jp2zh-subtitle-tool.exe，再点模型状态右侧的“管理模型…”：

- 点“选择当前配置所需模型”，确认下载来源，再点“开始下载”。
- 勾选的模型会按界面顺序逐个下载；取消后保留未完整文件，下次会继续下载。
- 已安装模型可手动勾选后重新下载；删除模型会先弹出二次确认。
- “HF-Mirror（第三方）”适合公开模型，程序不会把本机缓存的 Hugging Face 私有令牌
  发送给该镜像。
- 默认勾选“优先使用 Hugging Face/Xet（推荐）”，失败时自动切换兼容 HTTP；如果该方式
  在本机容易卡住，可取消勾选，直接使用支持断点续传的兼容 HTTP。
- 如果官方站或镜像速度不理想，可勾选“使用代理”并填写 Windows 代理地址，例如
  http://127.0.0.1:7890。代理对两种下载模式都生效。
- 速度是本次下载会话从启动至当前的平均值；“显示下载详情”可查看所用下载源、代理、
  当前模型和错误信息。

如果界面没有“管理模型…”（例如已发布的 Beta 5），或希望手动下载，请在程序根目录
打开 PowerShell 或命令提示符，然后逐条执行。不要混用两种终端的
代理设置语法。PowerShell 默认不从当前目录查找命令，因此下面统一使用 .\hf.cmd；
该写法在命令提示符中也可用。

注意：“优先使用 Hugging Face/Xet”和兼容 HTTP 是 GUI/项目下载器的选项。
hf.cmd 包装的是 Hugging Face 官方 CLI，不接受 --download-backend 参数，请不要把该
参数附加到下面的 hf.cmd download 命令。

如果直连 Hugging Face 较慢或无法访问，可先在同一个终端中设置 Windows 代理
（端口请按代理软件的实际设置修改）。

PowerShell：

$env:HTTPS_PROXY = "http://127.0.0.1:7890"
$env:HTTP_PROXY = "http://127.0.0.1:7890"

命令提示符（CMD）：

set HTTPS_PROXY=http://127.0.0.1:7890
set HTTP_PROXY=http://127.0.0.1:7890

.\hf.cmd download litagin/anime-whisper --local-dir models\anime-whisper

.\hf.cmd download TransWithAI/Whisper-Vad-EncDec-ASMR-onnx model.onnx --revision 6ac29e2cbf2f4f8e9b639861766a8639dd666e9c --local-dir models\whisperseg

.\hf.cmd download Qwen/Qwen3-ForcedAligner-0.6B --local-dir models\Qwen3-ForcedAligner-0.6B

.\hf.cmd download SakuraLLM/Sakura-GalTransl-7B-v3.7 Sakura-Galtransl-7B-v3.7.gguf --local-dir models\Sakura-GalTransl-7B-v3.7-GGUF

默认 Anime + GalTransl 简体中文/繁体中文流程需要上述四个模型。

3. 可选模型

Qwen ASR：
.\hf.cmd download Qwen/Qwen3-ASR-1.7B --local-dir models\Qwen3-ASR-1.7B

Sakura 14B 中文翻译：
.\hf.cmd download SakuraLLM/Sakura-14B-Qwen2.5-v1.0-GGUF sakura-14b-qwen2.5-v1.0-iq4xs.gguf --local-dir models\Sakura-14B-Qwen2.5-v1.0-GGUF

Sugoi 14B 实验性英文翻译（英文输出建议人工复核）：
.\hf.cmd download sugoitoolkit/Sugoi-14B-Ultra-GGUF Sugoi-14B-Ultra-Q4_K_M.gguf --local-dir models\Sugoi-14B-Ultra-GGUF

说话人性别着色：
.\hf.cmd download JaesungHuh/voice-gender-classifier --local-dir models\voice-gender-classifier

4. 启动

双击 jp2zh-subtitle-tool.exe。

界面可切换简体中文、繁体中文和英文。字幕目标支持简体中文、繁体中文及实验性英文；
英文目标会使用 Sugoi，且翻译结果建议人工复核。

5. 校验

- SHA256SUMS 用于校验按顺序重组后的原始 .7z 程序包。
- SHA256SUMS.parts 用于直接校验下载的各个分卷。
